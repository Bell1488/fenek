# Sirokko.pro — подключение Метрики и Яндекс Директа

## Подключение

1. Создайте новый счётчик для `https://sirokko.pro` (и www как дополнительный адрес). ID старого счётчика Fenek не используйте.
2. Укажите его числовой ID в `dist/config.js`: `metrikaId: ВАШ_ID`. Код счётчика подключается этим файлом на обеих страницах. Не добавляйте второй такой же код через хостинг или GTM.
3. Подключите счётчик к рекламной кампании Директа. Создайте цели ниже в интерфейсе Метрики: **JavaScript-событие**, идентификатор строго как в таблице.
4. Метрика и Вебвизор подключаются автоматически при загрузке страницы.

## Цели

| Идентификатор | Когда срабатывает | Назначение |
|---|---|---|
| `lead_success` | API подтвердил доставку в Telegram | Основная конверсия всего сайта |
| `payment_lead_success` | Доставлена заявка на пополнение/выкуп/оплату | Конверсия кампаний платежей |
| `cargo_lead_success` | Доставлена заявка на карго | Конверсия кампаний доставки |
| `lead_open` | Открыта быстрая форма либо посетитель вошёл в поле встроенной формы | Диагностика |
| `lead_start` | Начато заполнение контакта/комментария/суммы | Диагностика |
| `lead_submit` | Валидная форма передана серверу | Попытки, не подтверждённые лиды |
| `lead_error` | API/сеть не подтвердили доставку | Контроль ошибок |
| `telegram_click` | Переход по ссылке в Telegram | Вспомогательное действие |
| `max_click` | Переход по ссылке в MAX | Вспомогательное действие |
| `cargo_calculate` | Выбран расчёт карго для заявки | Вовлечённость |
| `exchange_select` | Изменён получатель в форме обмена | Вовлечённость |

Один успешный лид вызывает общую цель и одну профильную. **Не складывайте их как три разных лида.** В кампании выбирайте одну основную конверсию: `payment_lead_success` для платежей, `cargo_lead_success` для карго либо `lead_success` для смешанного трафика. Клики по Telegram / MAX и `lead_submit` не равнозначны доставленной заявке. Автоцель отправки формы может срабатывать ещё до подтверждения API, поэтому основной конверсией здесь служит JavaScript-цель успеха.

Идентификаторы добавлены в код, но сами цели и привязку к кабинету нужно создать в Метрике/Директе: доступа к этим кабинетам в комплекте нет.

## Разделение посадочных страниц

- Пополнение Alipay / WeChat, оплата поставщикам, выкуп: `https://sirokko.pro/`.
- Карго: `https://sirokko.pro/cargo.html`.
- Отдельные группы для каждого намерения; текст объявления должен соответствовать услуге и подтверждённым условиям. На сайте нет фиктивных отзывов, обещания фиксированного курса или гарантированной цены доставки.

## Разметка переходов

Пример UTM-шаблона для поля параметров URL в Директе:

```
utm_source=yandex&utm_medium=cpc&utm_campaign={campaign_id}&utm_content={ad_id}&utm_term={keyword}
```

Автоматическую разметку `yclid` настройте в кампании. Сайт сохраняет разрешённые UTM и yclid в пределах сеанса и добавляет их в доставляемую заявку. Контакты и текст заявки в события целей не передаются.

## Проверка до расхода бюджета

1. Откройте Sirokko.pro, разрешите аналитику, проверьте загрузку нужного счётчика.
2. Откройте форму и начните ввод: проверьте `lead_open`, `lead_start`.
3. Отправьте реальную тестовую заявку. Убедитесь, что сообщение дошло в рабочий чат, затем сработали `lead_success` и ровно одна профильная цель.
4. Проверьте карго, форму Hero, нижнюю форму и короткую модальную заявку на телефоне.
5. На тестовом сервере с неверным прокси должен быть отказ отправки и **никакого** `lead_success`. В рабочем сервере настройки для проверки не ломайте.
6. Обновление страницы и повтор той же доставленной заявки не должны создавать дубли.
7. Проверьте, что ссылка MAX и Telegram ведёт нужному менеджеру, а политика и реквизиты соответствуют ООО «Сирокко».
